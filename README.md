# Claude Skills — Romane

Skills personnels pour Claude Code, utilisables sur tous les projets.

- [`interview-specs/`](interview-specs/SKILL.md) — interroge une question à la fois pour écrire un cahier des charges d'automatisation complet, sans zone de flou, avant toute solution technique.
- [`hostile-review/`](hostile-review/SKILL.md) — attaque activement un projet terminé (exécute, teste, cherche à le casser, vérifie en ligne) plutôt que de le relire passivement.
- [`doubt-driven-development/`](doubt-driven-development/SKILL.md) — ne jamais présenter une hypothèse comme un fait ; vérifier avant d'affirmer, et se relire/tester soi-même avant de livrer.

## Installation

Copier le dossier d'un skill dans `~/.claude/skills/` (personnel, tous projets) ou `<projet>/.claude/skills/` (spécifique à un projet).
